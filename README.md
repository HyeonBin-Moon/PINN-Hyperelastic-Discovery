# Physics-Informed Neural Network-Based Discovery of Hyperelastic Constitutive Models

This repository provides the official implementation of the paper:

**Hyeonbin Moon†; Donggeun Park†; Hanbin Cho; Hong-Kyun Noh; Jae Hyuk Lim\*; Seunghwa Ryu\***
*Physics-informed neural network-based discovery of hyperelastic constitutive models from extremely scarce data*
Computer Methods in Applied Mechanics and Engineering 446 (2025) 118258.

† Equal contribution. \* Corresponding authors.

The paper is available at:
https://doi.org/10.1016/j.cma.2025.118258

This code implements a physics-informed neural network (PINN) framework that discovers the
**strain energy density** of hyperelastic materials from **extremely scarce data**: displacements
at a few points and resultant reaction forces from a single test.

---

## Overview

Discovering a constitutive model usually requires stress–strain data or full-field displacement
measurements. This framework works with much less data. It reconstructs the full displacement
field from sparse measurements and, at the same time, selects a parsimonious strain energy density
from a library of candidate terms.

The framework consists of three components:

- **PINN with finite element discretization.**
  A neural network takes the reference coordinates of the mesh nodes and the loading step as input,
  and predicts the nodal displacements. Deformation gradients are computed with finite element
  shape functions (linear triangles) instead of automatic differentiation, so the many candidate
  terms can be evaluated cheaply.

- **Weak-form force equilibrium with a candidate library.**
  The strain energy density is a linear combination of **57 candidate terms** in the invariants
  $\bar I_1$, $\bar I_2$ and $J$:

  - generalized Mooney–Rivlin terms
  - Hartmann–Neff-type terms
  - polynomial and logarithmic volumetric terms

  The force equilibrium is assembled as a system that is linear in the coefficients. Interior
  degrees of freedom must carry zero net force, and the boundary degrees of freedom must reproduce
  the measured resultant reaction forces.

- **Two-stage training.**
  - **Stage 1:** Adam updates the network parameters and the constitutive coefficients together.
  - **Stage 2:** two updates alternate.
    - L-BFGS refines the network.
    - Lp-regularized sparse regression ($p = 1/4$) updates the coefficients and drives most of
      them to zero.

## Problem Setting

A plate with a central circular hole is modeled as one quarter, using symmetry. Displacement-controlled
loading is applied over 10 loading steps:

- tension in both in-plane directions
- compression in the thickness direction

Because the displacement is uniform through the thickness, each step is in a plane strain state.

| Quantity | Setting |
|:--|:--|
| Geometry | 100 × 100 quarter plate, hole radius 50, thickness 1 |
| Top edge | $u_y = \delta = 100$ |
| Right edge | $u_x = \delta / 2 = 50$ |
| Bottom / left edges | Symmetry ($u_y = 0$ / $u_x = 0$) |
| Thickness direction | $u_z = -0.5$ |
| Loading steps | 10 |

Only the following measurements are used:

- in-plane displacements at **5 points on the hole edge** (0°, 22.5°, 45°, 67.5°, 90°)
- the **resultant reaction forces** on the four edges

## Data

Training data are generated by finite element simulations in Abaqus, using a user hyperelastic
material subroutine (UHYPER). The same mesh is used for the forward simulation and the inverse
analysis.

| Quantity | Setting |
|:--|:--|
| Mesh | 2,185 nodes in the plane; 4,179 linear triangles (one layer of Abaqus C3D6 wedge elements, element size 2) |
| Frames | 11 (initial state and 10 loading steps) |

Data are stored in
`FEM_Data/Circular_Hole_One_Quarter_Model/Hole_Radius_50_Tension_100_Plane_Strain_F33_-0.5/<model>/`.
`<model>` is one of `NH2`, `NH4`, `IH`, `HW`, `MR2`, `MR4`, `YH` or `HN`.

| File | Shape | Content |
|:--|:--|:--|
| `displacements.npy` | (11, 4370, 4) | `[node_label, U1, U2, U3]` of every node of the 3D mesh |
| `reaction_forces_{TOP,BOT,RIGHT,LEFT}_LINE.npy` | (11, n_edge, 4) | `[node_label, RF1, RF2, RF3]` at the nodes of each edge |
| `Input_DG.inp` | — | Abaqus input file with the mesh and the node sets `Top_line`, `Bot_line`, `Right_line`, `Left_line`, `Hole_line` |

The 3D wedge mesh has two node layers. The script keeps the first layer as the 2D mesh and sums the
reaction forces of both layers.

The `.npy` files were written by Abaqus Python (Python 2), so NumPy may print a harmless warning when
loading them.

## Benchmark Models

Eight benchmark hyperelastic models are used as ground truth:

| Benchmark | Strain energy density $W$ |
|:--|:--|
| **NH2** (Neo-Hookean) | $0.5(\bar I_1-3) + 1.5(J-1)^2$ |
| **NH4** (Neo-Hookean) | $0.5(\bar I_1-3) + 1.5(J-1)^4$ |
| **IH** (Isihara) | $0.5(\bar I_1-3) + 1.0(\bar I_2-3) + 1.0(\bar I_1-3)^2 + 1.5(J-1)^2$ |
| **HW** (Haines–Wilson) | $0.5(\bar I_1-3) + 1.0(\bar I_2-3) + 0.7(\bar I_1-3)(\bar I_2-3) + 0.2(\bar I_1-3)^3 + 1.5(J-1)^2$ |
| **MR2** (Mooney–Rivlin) | $0.5(\bar I_1-3) + 1.0(\bar I_2-3) + 1.5\ln(J)^2$ |
| **MR4** (Mooney–Rivlin) | $0.5(\bar I_1-3) + 1.0(\bar I_2-3) + 1.5\ln(J)^4$ |
| **YH** (Yeoh) | $0.5(\bar I_1-3) + 0.7(\bar I_1-3)^2 + 0.3(\bar I_1-3)^3 + 1.5\ln(J)^2$ |
| **HN** (Hartmann–Neff) | $0.5(\bar I_1-3) + 1.0(\bar I_2^{3/2}-3^{3/2})^2 + 1.5(J-1-\ln J)$ |

The 57 candidate terms are indexed as follows:

| Index | Candidate terms |
|:--|:--|
| 0–34 | $(\bar I_1-3)^{j-i}(\bar I_2-3)^{i}$, $j = 1,\dots,7$, $i = 0,\dots,j$ |
| 35–41 | $(J-1)^{2k}$, $k = 1,\dots,7$ |
| 42–48 | $(\bar I_2^{3/2}-3^{3/2})^{i}$, $i = 1,\dots,7$ |
| 49–55 | $\ln(J)^{2k}$, $k = 1,\dots,7$ |
| 56 | $J-1-\ln J$ |

## Training Settings

These are the defaults in `PINN/utils/config.py` and `PINN/train.py`:

| Quantity | Setting |
|:--|:--|
| Network | Input $(x, y, t)$ → 7 fully connected layers of 32 units → $(u_x, u_y)$; SiLU activation |
| Weight initialization | Xavier uniform |
| Stage 1 | Adam, learning rate $5\times10^{-4}$ for both the network and the coefficients, 20,000 epochs, gradient-norm clipping at 1.0 |
| Stage 2 | 10 alternating cycles of the two updates below |
| Stage 2: network update | L-BFGS, `max_iter` 2,000 |
| Stage 2: coefficient update | Lp sparse regression, $p = 1/4$, threshold $10^{-3}$, best of 9,001 initial guesses |
| Regularization weight $\lambda_p$ | Weight × $\sum F^2$; weight $3\times10^{-3}$ for NH2, NH4, IH, MR2, MR4, YH; $10^{-3}$ for HW; $2\times10^{-3}$ for HN |
| Data loss weight | 0.5 on the measurement points |
| Noise levels | 0 %, 1 %, 3 %, 5 % Gaussian noise on the measured displacements and resultant forces |
| Random seed | 13 (PyTorch) |

> **Note.**
> The default settings are the last ones used. They may differ slightly from those reported
> in the paper; adjust them as needed. `set_seed` seeds PyTorch only. The measurement noise is drawn
> with NumPy, so noisy runs vary slightly between executions.

```text
PINN/
  train.py                       entry point: Stage 1 + Stage 2 model discovery
  utils/
    config.py                    default settings and constants
    mesh.py                      mesh reading, 3D-to-2D reduction, B matrices, measurement points
    data.py                      loading of FEM data and noise
    library.py                   invariants and the 57-term candidate library
    network.py                   PINN and constitutive-parameter modules
    loss.py                      weak-form force equilibrium and data losses
```

## Installation

```bash
pip install -r requirements.txt
```

The code needs Python 3.9 or later with PyTorch, NumPy, SciPy, Matplotlib and tqdm. A CUDA GPU is
recommended. One discovery run (one model at one noise level) takes about two hours on an NVIDIA
RTX 4090: about one hour for Stage 1 and one hour for Stage 2.

## Usage

Run from the repository root:

```bash
python PINN/train.py                               # all 8 models x 4 noise levels
python PINN/train.py --model HN --noise 0.01       # one model, one noise level
python PINN/train.py --model MR2 --noise all       # one model, all noise levels
python PINN/train.py --help                        # all options
```

| Option | Default | Meaning |
|:--|:--|:--|
| `--model` | `all` | `NH2`, `NH4`, `IH`, `HW`, `MR2`, `MR4`, `YH`, `HN` or `all` |
| `--noise` | `all` | noise level (e.g. `0.01`) or `all` = 0, 0.01, 0.03, 0.05 |
| `--epochs-adam` | 20000 | Stage 1 epochs |
| `--ado-iters` | 10 | Stage 2 cycles |
| `--lbfgs-max-iter` | 2000 | L-BFGS iterations per Stage 2 cycle |
| `--num-guesses` | 3000 | sparse regression: rounds of 3 random initial guesses |
| `--seed` | 13 | PyTorch random seed |
| `--output-dir` | `PINN/Model_Save` | output folder |
| `--show-plots` | off | show intermediate diagnostic figures during training |

For each model and noise level, the script writes the following to the output folder. The default
`PINN/Model_Save/` is not part of the repository.

| File | Content |
|:--|:--|
| `Params_<tag>.jpg` | Final coefficients compared with the ground truth |
| `Loss_<tag>.jpg` | Loss history |
| `Loss_<tag>.npy` | Loss history (raw) |
| `Consitutive_parameter_<tag>.npy` | History of the 57 coefficients |
| `AI_Model_<tag>` | PyTorch checkpoint (`model_state_dict`, `constitutive_params_state_dict`) |

`<tag>` is `<model>_Noise_<noise>_Trial_<trial>`.

With `--show-plots`, intermediate figures are shown during training: displacement, invariant and
stress fields, the coefficients, and the loss.
